# The cast on Battlefield: build once with LLCHAR=file and run once per
# fighter (TM/llchar.txt), as tools/harness/run_tests.py does. A rising
# aerial interrupt with nair onto the right platform from a full hop under

# lands the fighter while still rising (trace on: vy > 0 on the landing),

# fighters the two fixed timings miss. Debug Log on so the trace and LLROUTE
# lines reach the log after the script ends. Then the ledge route, for the
# fighters that have one (no LLROUTE play line: none).
