# Assist: Assist stops on each step of the route and waits for the input.
# These only set up and hang; the script ends, then the pad (pad.py) plays
# the route with each input a little late, so the wait shows. Cut to the
# touchdown plus 40 frames. assist.gif (README) is assist-1s.

preset load Ledge Drill
set Ledge/Assist = 1
set Ledge/Assist Wait = 0

sync assist-5s
mark clip assist-5s in: the script ends here; drive the route by pad, each input late
