# Conventions

- `context-layout.md`: the standard for storing and navigating context in any project (compact indexes, path-triggered rules, skills, progressive loading, budgets).
- `incident-protocol.md`: when and how an agent logs a problem, what "honest reasoning" means, how to resolve, what the hooks remind you of.
- `rca-protocol.md`: the weekly review: adaptive depth, delegation by model, insight operations, report format, what counts as an insight.
- `tags.md`: the tag registry (add a tag here before using it widely).
- `project-template/`: files to drop into a new project (CLAUDE.md, AGENTS.md, a rules file, docs/INDEX.md).
