# Camera views alone, with no menuing: build with
# LLSCRIPT=src/landinglab_views_test.txt and start the event.
autorun
# Camera views: save the camera as it is, hold it while Falcon runs a few
# steps (staying on stage), then bring it back after the card is read again.
# Each "view show" logs where the camera is and whether that's view 1.
script Camera views
start 0 0 right
30
view save 1
mark view 1 saved: expect an LLVIEW saved line with real numbers
# the card write that follows can swallow log lines for a while: wait it out
120
15 s:1,0
view show 1
shot view held: the camera stayed put while Falcon ran right (show: matches)
set Camera/Camera Mode = 0
set Camera/View = 0
30 s:-1,0
view show 1
shot normal camera again: following Falcon (show: differs)
view load 1
5
view show 1
shot view 1 back: the same framing as the first view shot (show: matches)
closemenu
card flush
set Camera/Camera Mode = 0
set Camera/View = 0
card restart
10
view show 1
shot after the card is read again: view 1 framing once more (show: matches)
set Camera/Camera Mode = 0
set Camera/View = 0
closemenu
card flush
mark views done
