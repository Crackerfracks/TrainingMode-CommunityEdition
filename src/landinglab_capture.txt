# Character capture for tools/llsim: build with
#   LLSCRIPT=src/landinglab_capture.txt LLCHAR=CKIND_<NAME> [LLSTAGE=...]
# and start the event. It dumps the fighter and stage (LLDUMP), then plays
# each tracked animation whole while held in the air, learning its ECB
# frame by frame from a clean slate, and writes the table (LLECB, LLLEN).
# The character's own states seen in the air (its specials, Kirby's and
# Jigglypuff's air jumps) are caught too, by state id (LLSPEC, LLSPECLEN).
# Game & Watch's own nair, bair and uair (347-349) are learned in the
# aerial slots (6, 8, 9), and by state id as well.
# With LLCHAR=file one build serves every character: the fighter is the
# CKIND_ number in TM/llchar.txt (LLCHARFILE=<file> ./build.sh ...).
# Each dump also logs the checks (LLCHECK): the first on Falcon's baked
# table with this character's physics (llsim check <log>), the last on
# the table just captured.
autorun

script Capture
preset load Defaults
set Jump/Show = 0
start 0 0 right
60
