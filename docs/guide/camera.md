# Camera

The Camera menu sets the camera mode and lets you save and name camera views for each stage.

Eight saved views per stage, each with a name up to 12 letters long. You can name one FALCON CAM. Nobody will stop you.

## Options

The Camera menu, in menu order.

| Option | Values | Default | What it does |
| --- | --- | --- | --- |
| Camera Mode | Normal, Zoom, Fixed, Advanced | Normal | Adjusts the camera's behavior. In Advanced mode, use the C-stick while holding A, B or Y to pan, rotate and zoom, respectively. |
| View | None, View 1 to View 8 | None | Jumps the camera to a saved view, in Advanced mode so you can still move it. Each stage has its own 8 views. Presets keep which one they were saved with. |
| Save View | Press A | n/a | Keeps the camera as it is now as the view picked above, on this stage. Set it up in Advanced mode, or pause on a moment you like. |
| Name View | Press A | n/a | Gives the view picked above a name. Save it first. |

## Views

Each stage has 8 view slots. An unsaved slot reads "View N (empty)". Picking an empty view plays the error sound. A saved slot reads "View N", or the name you gave it.

To make a view:

1. Set Camera Mode to Advanced.
2. Hold A, B or Y and move the C-stick to pan, rotate or zoom.
3. In View, pick a slot. Pick one other than None.
4. Press A on Save View.
5. Press A on Name View to name it, if you want. The name grid opens, with names up to 12 letters. The grid is described in [Presets](presets.md#saving-and-naming).

Views belong to the stage. The same slot on another stage is a different view. A preset keeps which view number it was saved with, not the view's contents.

## Tips

- Pause on a moment you like with Frame Advance, then save the view.

## Speed menu

The Speed menu slows the game down and sets up Frame Advance. It is in the main Landing Lab menu, after Camera.

| Option | Values | Default | What it does |
| --- | --- | --- | --- |
| Game Speed | 1, 5/6, 2/3, 1/2, 1/4 | 1 | Slows the game down to practice. |
| Frame Advance | Off, On | Off | Freezes the game and steps one frame per press of the Advance Button, or holds it to step slowly. D-pad down turns this on and off at any time. Presets do not store it. |
| Advance Button | L, Z, X, Y, R | Z | The button that steps a frame while Frame Advance is on. The game does not see it. |

Frame Advance is how you check a cue against what happened. D-pad down turns it on. With it on, the Advance Button steps one frame, and holding it steps slowly. In Frame Advance, count the frame you pressed on when you report a cue that was wrong. See [Troubleshooting](troubleshooting.md).

The D-pad does nothing while a trigger is partway in, so shielding cannot turn Frame Advance on by accident.
