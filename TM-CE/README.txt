TM-CE + Landing Gear
====================

An unofficial build of Training Mode - Community Edition v1.4 with one new
event, Landing Gear: a trainer for no-impact landings, aerial interrupts,
wavelands and ledge routes, for the whole cast. Not made or supported by the
TM-CE team: it is AI-written code in a fork, so send feedback to the fork
below, not to the TM-CE Discord or repository.

You need your own Super Smash Bros. Melee NTSC 1.02 ISO.

Windows:
    Drag your Melee ISO onto "DRAG VANILLA MELEE HERE.bat".

Linux / macOS:
    Install xdelta first (sudo apt install xdelta3, sudo pacman -S xdelta3,
    or brew install xdelta), then run:
        ./build_linux_and_mac.sh path/to/melee.iso

Either way you get TM-CE-LandingGear.iso in this folder. Open it in Dolphin.
The patch fails on anything but a clean NTSC 1.02 ISO.

In game: Event Mode > Character-specific Tech > Landing Gear, the last event
on the page. Pick any fighter and Battlefield. Start opens the menu; the
Help row in it is the color legend and the Controls row lists every button.

Your first minute: run off the left platform, double jump toward the top
one, and press A when a solid pink cell reaches the white gate. You land on
the frame you pressed. That is an aerial interrupt.

How to use it, known limits and where to send feedback:
https://github.com/Crackerfracks/TrainingMode-CommunityEdition
