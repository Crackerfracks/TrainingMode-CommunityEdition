First public build of **Landing Lab**, a Captain Falcon event added to Training Mode - Community Edition v1.4. It shows NILs, aerial interrupts and perfect wavelands before you land, and teaches the ledge routes that keep the most GALINT, frame by frame.

This is an unofficial build, not made or supported by the TM-CE team. Landing Lab's code was written with Claude, an AI coding assistant, so please send feedback here rather than to TM-CE.

## Install

You need your own Melee NTSC 1.02 ISO. The zip holds only a patch.

1. Download `TM-CE-LandingLab-0.6.5.zip` below and unzip it.
2. Windows: drag your ISO onto `DRAG VANILLA MELEE HERE.bat`. Linux/macOS: install xdelta, then run `./build_linux_and_mac.sh path/to/melee.iso`.
3. Open the new `TM-CE-LandingLab.iso` in Dolphin. Event Mode → Character-specific Tech → Landing Lab. Start opens the menu.

## What's in it

- Green, pink and cyan cues for NILs, aerial interrupts and perfect wavelands, at the landing spot and on Falcon.
- Landing and body paths with markers where each input is due, and a frame timer that counts down to each press.
- A controller display with the axis deadzone band and a fastfall line.
- Ledge Practice: the top NIL and AI routes by GALINT for each ledge, with an Assist mode that freezes on each input until you get it.
- Frame Advance on D-pad down, position save and load on D-pad right and left.

How to read everything, the menu, known limits and how to build it yourself: see the [README](https://github.com/Crackerfracks/TrainingMode-CommunityEdition#readme).
