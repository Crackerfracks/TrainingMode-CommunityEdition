# Shared knowledge base (kb)

Every problem that costs more than one attempt, every wrong assumption, every workaround and every misread of the user is logged: `kb new "title" --tags a,b --what "..."` the moment you notice it, then `kb note ID --section reasoning "<honest best guess at why the decision felt right>"` and `kb resolve ID --resolution "..."`. The `kb` skill has the short form; `~/kb/conventions/incident-protocol.md` the full one. A weekly review turns incidents into the insights imported below; read the domain file (`~/kb/insights/<domain>.md`) when a task enters that area, and treat them as corrections to your thinking, not as a checklist.

Navigating any project: index first (`INDEX.md`, `CLAUDE.md`), then the one-line summary, then the file. Search (`rg`) when the index is silent, then fix the index. Never bulk-read a directory. Standard: `~/kb/conventions/context-layout.md`.
