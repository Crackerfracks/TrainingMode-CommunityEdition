## I-0006 A number without its convention is not a number
- tags: research,data,communication
- weight: 2
- status: active
- added: 2026-W42
- evidence: seed: frame-counting convention note in project memory
- history: 2026-W42 add

**Correction.** When you report or compare counts, frames, times or coordinates, state the convention (zero- or one-based, which frame the press lands on, which clock, which units) next to the value. When two sources disagree by one, suspect the convention first.

**Faulty pattern it replaces.** Comparing values from two conventions as if they were the same scale, then 'fixing' a correct value.

**Applies when.** Frame data, timers, offsets, any off-by-one dispute.
