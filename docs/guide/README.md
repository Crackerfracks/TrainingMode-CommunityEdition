## The cast

Every slot on the character select works: Mario, Dr. Mario, Luigi, Bowser, Peach, Yoshi, Donkey Kong, Captain Falcon, Ganondorf, Falco, Fox, Ness, Ice Climbers (as Popo), Kirby, Samus, Zelda and Sheik, Link, Young Link, Pichu, Pikachu, Jigglypuff, Mewtwo, Mr. Game & Watch, Marth and Roy. Each one's jumps, falls, aerials and airdodge are measured from the game and built in. What differs per fighter, and the few things that don't work, are in [Troubleshooting](troubleshooting.md#limits).

## Controls

Every button Landing Gear uses outside the menu. The Controls row of the main menu lists the same thing in game.

| Input | Does |
| --- | --- |
| Start | Opens the menu. |
| D-pad right (hold) | Saves where you are. |
| D-pad left | Puts you back where you saved. With Reset starting from the ledge, it starts a new attempt instead; with a test script chosen, it plays the script again. |
| L or R clicked all the way + D-pad up or down | The quick menu: your presets and main settings over a frozen game. The stick plays on, B closes it. Trigger + A saves, trigger + X or Y saves new. |
| L and R both clicked all the way + D-pad up or down | Hides everything Landing Gear draws, or brings it back. With a trigger only partway in, the D-pad does nothing. |
| D-pad up, hanging from a ledge | The next ledge route in the list, and the first again after the last. |
| D-pad down | Frame Advance on or off. |
| Advance Button (Z unless you change it in Speed) | While frozen, steps one frame; hold it to step slowly. |

The Help row of the main menu is the color legend: green NIL, pink AI, cyan waveland, periwinkle GALINT, slate missed; solid cells press, hollow cells touch down, the white gate is now; the short hop path is dashed and the body path dotted. It is explained in [Cues](cues.md#cue-colors).
